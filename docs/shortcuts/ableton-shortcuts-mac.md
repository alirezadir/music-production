# 🎹 Ableton Live – Mac Keyboard Shortcuts (Full Markdown)

#### 🎛️ MIDI Editing

|                            |              |
|----------------------------|--------------|
| Toggle Draw Mode           | B            |
| Quantize                   | ⌘U           |
| Quantize Settings          | ⇧⌘U          |
| Move Selected Notes        | ↑ ↓ ← →      |
| Transpose MIDI Notes (Octaves) | ⇧↑ / ⇧↓  |
| Nudge MIDI Notes           | ⌘↑ ↓ ← →     |
| Lengthen / Shorten MIDI Note | ⌘⇧← / ⌘⇧→ |

#### 🎼 Parameter Mapping

|                        |      |
|------------------------|------|
| Toggle MIDI Map Mode   | ⌘M   |
| Toggle Key Map Mode    | ⌘K   |

#### 🎶 Create & Capture

|                          |              |
|--------------------------|--------------|
| Insert New Audio Track   | ⌘T           |
| Insert New MIDI Track    | ⇧⌘T         |
| Insert New Return Track  | ⌘⌥T         |
| Create New MIDI Clip     | Double-click |
| Capture MIDI             | ⌘⇧C         |
| Save Live Set As         | ⇧⌘S         |

#### 🎹 Computer MIDI Keyboard (Toggle with `M`)

|           |                 |
|-----------|-----------------|
| A - L     | C - B (white)   |
| W - O     | C# - A# (black) |
```
   C#  D#      F#  G#  A#      C#
   |   |       |   |   |       |
  [W] [E] [ ] [T] [Y] [U] [ ] [O]
[A] [S] [D] [F] [G] [H] [J] [K] [L]
 |   |   |   |   |   |   |   |   |
 C   D   E   F   G   A   B   C   D
```

#### ▶ Playback & Record

|                                 |         |
|---------------------------------|---------|
| Move Insert Marker to Start     | Fn ←    |
| Play/Pause                      | Space   |
| Play Selection Only (pause after) | ⇧Space  |
| Scroll Display to Follow Playback | ⌘⇧F     |
| Record to Arrangement           | Fn + F9 |
| Back to Arrangement             | Fn + F10|
